# 技术路线图 S1-FIGURE-STRATEGY 修订版：横向画布与三条竖向泳道

## 1. 修订原因

本版替代原先“纵向画布 + 三个上下堆叠分区”的正式方向。

新的构图规则：

```text
横向画布
+ 三条从左到右排列的竖向泳道
+ 每条泳道内部自上而下阅读
+ 章节之间从左向右交接
```

旧版 S1 策略保留为历史记录，不再作为后续正式图默认合同。

## 2. 图的角色与标题

本图是论文总技术路线图，用于回答：

```text
工程资料如何转化为多场景数据
-> 稀疏监测条件下如何完成 I/E 缺陷诊断
-> 诊断结果如何驱动监测节点布局优化
```

建议标题：

```text
面向城市排水管网渗入与渗漏缺陷的时空诊断及监测布局优化研究
```

术语规则：

- 图内使用 `I/E 缺陷`。
- 图注首次出现时展开为“渗入/渗漏（Infiltration/Exfiltration, I/E）缺陷”。
- 不使用“入渗入流与渗漏缺陷”。

## 3. 画幅

### 3.1 正式版画幅

推荐优先级：

```text
16:9 横向画布
-> A4 横向页面
```

设计阶段建议使用：

```text
2400 × 1350 px
```

论文正文中可横向整页展示，也可作为答辩 PPT 总览图直接使用。

### 3.2 总体分栏

将画布分为三条并排的竖向泳道：

| 位置 | 泳道 | 建议宽度 |
|---|---|---:|
| 左侧 | 第 3 章：SWMM/PySWMM 多场景仿真数据生成 | 36% |
| 中间 | 第 4 章：水力约束时空图缺陷诊断 | 38% |
| 右侧 | 第 5 章：诊断导向监测布局优化 | 26% |

中间泳道略宽，用于突出诊断模型内部机制。

## 4. 阅读路径

### 4.1 全局阅读路径

读者先从左到右识别三章递进关系：

```text
第 3 章：生成可信数据
-> 第 4 章：提取诊断证据
-> 第 5 章：优化监测决策
```

### 4.2 泳道内部路径

每条泳道自上而下阅读：

```text
输入
-> 技术模块
-> 中间结果
-> 本章交付
```

### 4.3 跨泳道交接

跨泳道只使用两条主要向右箭头：

```text

-> 稀疏观测时空图输入

固定布局诊断验证
-> 诊断评价驱动布局优化
```

不要使用复杂回环或双向箭头。

## 6. 中间泳道：第 4 章 水力约束时空图缺陷诊断

### 6.1 泳道标题

## 8. 模块层级

| 层级 | 视觉形式 | 用途 |
|---|---|---|
| L1 | 三条竖向虚线泳道 | 第 3、4、5 章 |

- 每张卡片最多两行；
- 中文优先；
- 保留必要缩写：`SWMM`、`PySWMM`、`DWF`、`I/E`、`residual`、`Top-K`；
- 仅保留必要符号：`p_active(t)` 与 `node_scores(t)`；
- 不在图内写完整句子。

## 12. 图注承接

图注负责说明：

1. `I/E` 表示渗入/渗漏（Infiltration/Exfiltration）。
2. 参照响应用于 residual 对齐，正常扰动样本用于表示合理波动并约束误报。
3. 诊断模型采用 full-graph sparse-observation：保留完整拓扑，仅监测节点具有有效动态观测。
4. 场景级报警、活跃时段和 Top-K 排序由 `p_active(t)` 与 `node_scores(t)` 沿时间聚合得到。
5. 第 5 章固定诊断协议，只改变监测节点集合与 observed mask。
6. 第 5 章展示方法演进和机制分析框架，不代表尚未统一协议复核的方法已经形成最终性能排序。

## 13. 图内省略

- 节点数、管段数、场景数和监测节点数；
- `IE420`、`normal20`、`degree_N25`、`lambda_loc`；
- 48 h、10 min、窗口长度和步长；
- 水质组分数量、方程和 residual 公式；
- 指标数值、排名和性能提升比例；
- `direct/near/far`、hard candidates、Jaccard、node_holdout 等实验术语；
- 旧路径、桥接证据、待重训细节和执行记录；
- 尚未实现的在线反馈回环。

## 15. 修订后的 S1 决策

正式版默认方向：

```text
横向画布 + 三条竖向泳道
```

全局阅读方向：

```text
从左到右：数据生成 -> 缺陷诊断 -> 布局优化
```

泳道内部阅读方向：

```text
从上到下：输入 -> 技术模块 -> 中间结果 -> 本章交付
```

核心视觉锚点：

```text
左侧：PySWMM 与 residual 特征
中间：水力传播关联建模与场景级聚合
右侧：诊断评价驱动布局优化与方法演进
```
