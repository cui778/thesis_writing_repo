## 3.2 SWMM基线模型构建

### 3.2.1 模型构建流程

SWMM基线模型的构建目标，是将研究子区工程资料转化为一个可独立运行、可批量注入缺陷并可输出节点级水力水质响应的仿真平台。该模型不仅用于描述正常工况下的管网运行状态，也为后续I/E缺陷场景注入、PySWMM自动化批量仿真以及节点级特征构造提供统一载体。因此，本节围绕模型结构、入流边界、水质背景、输出变量和合理性检查展开，重点说明后续缺陷数据生成所依赖的SWMM基础模型如何形成。

结合本文资料条件和多场景仿真需求，SWMM基线模型构建过程可概括为七个环节：工程资料整理、研究子区划分、管网结构概化、节点与管段属性整理、节点入流与边界条件设置、几何一致性与拓扑连通性检查、无缺陷正常工况层确定。

首先，对第2章所述工程资料进行分类整理。检查井坐标、管段连接关系、管径、管长和高程等管网资料用于构建SWMM节点与管段对象；泵站和闸门资料用于确定出流边界条件和调度规则；调蓄设施与河道资料用于设置Storage节点和下游水位边界；污水处理系统资料则用于支撑节点DWF基准流量估算。通过上述资料整理，原始工程信息被转化为SWMM模型可识别的拓扑、属性和边界输入。

其次，根据黄孝河-机场河流域排水分区、主干管汇流方向、泵站服务范围和上下游边界条件划定研究子区。研究子区并非对原始管网进行简单裁切，而是在保持主干管、次干管和关键支管连通关系的基础上，选取能够独立完成连续仿真的管网范围。对于外部边界，模型以出流口、调蓄单元或可表达的外部入流位置作为上下游接口，使研究子区既具有明确边界，又能保留主要水力传播路径。

在管网结构概化过程中，研究子区内检查井、管段、出流口和调蓄单元被分别转化为SWMM可表达的Junction、Conduit、Outfall和Storage对象。结构概化遵循“保留主干连通、保留关键汇入、保留边界控制、合并局部冗余”的原则：主干管、次干管、泵站或调蓄单元邻近节点以及水量水质波动较明显的区域优先保留；对于局部密集、属性相近且对I/E响应传播影响较小的末端支管，在不改变主要水力通道的前提下进行合并或简化。该处理有助于在保留缺陷响应空间传播关系的同时，提高后续多场景仿真的稳定性和计算效率。

模型结构确定后，进一步整理节点与管段属性。节点属性包括底高程、最大水深和初始水深；管段属性包括长度、断面形状、管径、糙率、进出口偏移和局部损失系数。其中，管段糙率参考SWMM中混凝土管道常用取值范围，并结合管网台账中的管材和管龄信息赋值。随后，依据服务面积、人口、用水量和入流比例等资料估算节点DWF基准流量，同时设置出流口、调蓄单元和上下游边界条件。水量与水质背景输入均被组织为SWMM可调用的时间序列格式，以保证后续正常工况和缺陷工况运行在同一模型结构与同一类背景输入机制下。

模型导入SWMM后，对节点坐标、管段连接关系、断面属性、高程关系和边界对象进行几何一致性与拓扑连通性检查。该步骤主要用于消除工程资料格式转换和研究子区提取过程中可能产生的断链、错误连接或边界设置异常，确保无缺陷正常工况和I/E缺陷场景均在同一稳定拓扑结构上运行。

最后，以DWF为常态水量输入，结合背景水质浓度，构建无缺陷正常工况层。该正常工况层不是一个固定不变的静态状态，而是在相同模型结构、边界条件和正常输入机制下生成的一组无缺陷运行样本。其中，一个无缺陷样本被指定为reference场景，用于与缺陷场景逐时刻对齐并计算residual；其余normal扰动样本用于描述无缺陷运行状态下的合理波动范围，并在后续诊断模型训练与评价中约束正常工况误报。由此，SWMM基线模型既提供了缺陷注入前的正常背景，也为后续raw、residual和relative residual特征构造提供了对齐基准。

上述环节完成后，形成了包含管网拓扑、节点与管段属性、出流边界、调蓄单元、DWF入流和水质背景输入的SWMM基础模型。后续I/E缺陷场景并不重新定义管网系统，而是在该基线模型及其正常输入机制上叠加受控水量扰动，从而生成可比较、可追溯的多场景水力水质响应。

### 3.2.2 DWF输入与水质背景设置

在正常工况下，本文以旱流输入（Dry Weather Flow，DWF）作为常态水量输入基础。节点DWF基准流量按照服务面积、人口密度、人均生活用水量和入流比例估算，用于表示不同服务区域在无降雨和无缺陷条件下的常态污水入流。考虑到生活污水排放具有明显日内变化，模型在节点基准流量基础上引入24 h小时变化系数 `Hourly_STD`；同时，为反映不同日期之间的负荷差异，设置7 d日尺度变化系数 `Week_STD`。在时间序列构造过程中，进一步叠加小幅随机扰动，使正常工况在保持总体日变化规律的同时具备一定非平稳性。

在具体实现上，节点DWF不只作为SWMM `[DWF]` 模块中的常量基准项使用，而是被展开为168 h显式小时流量序列。每个入流节点对应一条 `DWF_*` 流量时间序列，模型在仿真过程中从 `[TIMESERIES]` 模块读取当前时刻的流量边界。本文正式数据生成统一截取48 h连续观测窗口，因此模型在正式场景生成过程中调用一周时间序列中对应的48 h动态输入片段。这里的48 h并非对I/E缺陷实际持续时间的假定，而是为了在相同观测尺度下比较正常运行响应和不同缺陷响应；缺陷是否发生、开始时刻和持续时间由后续缺陷矩阵中的 `start_hour` 和 `duration_h` 单独控制。

研究子区128个节点的DWF基准流量存在明显差异，反映出不同服务区域的人口密度、汇水面积和用地类型差异。节点基准流量分布如表3-1所示。全节点平均基准流量为36.1 L/s，标准差为10.2 L/s，流量量级从低于1 L/s的末端节点到超过200 L/s的主干管或泵站前池节点，跨越多个数量级。其中，基准流量在1–50 L/s范围内的节点共97个，占75.8%，构成研究子区常态入流的主体；超过100 L/s的节点共13个，主要位于主干箱涵交汇区和泵站前池附近。

**表3-1  研究子区节点DWF基准流量分布**

| 基准流量范围（L/s） | 节点数量 |    占比 | 典型节点类型       |
| ----------: | ---: | ----: | ------------ |
|         < 1 |    6 |  4.7% | 管网末端、低密度区检查井 |
|        1–10 |   53 | 41.4% | 支管汇入节点       |
|       10–50 |   44 | 34.4% | 次干管节点        |
|      50–100 |   12 |  9.4% | 主干管节点        |
|     100–200 |    7 |  5.5% | 主干箱涵交汇节点     |
|       > 200 |    6 |  4.7% | 泵站前池及主干出口节点  |

上述流量分布说明，不同节点的常态水量基础存在显著差异。若直接使用原始流量作为模型输入，高流量节点的数值尺度容易在训练过程中占据主导，而低流量节点的相对异常可能被削弱。因此，后续3.5节在原始输出变量基础上进一步构造residual和relative residual特征，用于削弱节点基准量级差异对模型输入的影响，并突出相对于正常运行状态的异常响应。

水质输入与水量输入采用同一时间组织方式。模型将水流量 `FLOW` 与污染物浓度 `CONCEN` 统一组织到 `[INFLOWS]` 模块，并通过 `[TIMESERIES]` 描述小时尺度变化。当前SWMM模型中配置的水质组分包括BODf、BODs、NH4、NO3、DO、TSSs、TSSn、TR_in和TR_ww共9种，覆盖有机物、氮素、溶解氧、悬浮物和示踪组分等类别。该配置用于保证SWMM水质输移和背景状态的完整性；后续诊断模型的正式输入特征将在3.5节结合变量可获取性、相关性和I/E响应敏感性进一步筛选。

### 3.2.3 水质反应配置

本文水质模拟采用“水量—浓度同通道输入、管网输移、Storage节点反应”的组织方式。入流节点通过 `[INFLOWS]` 接收DWF流量和背景污染物浓度，管段承担水流输移和部分水质衰减，Storage节点则用于表达具有蓄水体积和停留时间的调蓄单元内的水质转化。

模型在 `[POLLUTANTS]` 中定义BODf、BODs、NH4、NO3、DO、TSSs、TSSn、TR_in和TR_ww等组分，并在 `[INFLOWS]` 中为入流节点配置背景浓度序列。背景浓度与DWF流量采用相同的时间组织方式，均由 `[TIMESERIES]` 驱动。不同组分在管段输移过程中的处理方式并不完全相同：BODf、BODs和TSSs设置一阶衰减系数，分别用于表示快速可降解有机物、缓慢可降解有机物和可沉降悬浮物在管网输移过程中的衰减；NH4、NO3、DO、TSSn、TR_in和TR_ww在 `[POLLUTANTS]` 模块中未设置管道一阶衰减或伴随污染物转化，可近似视为管段中的保守输移组分。因此，当前正式模型中的氮素转化主要不在管段一阶衰减项中表达，而是在具有停留时间的Storage节点中表达。

Storage节点的水质转化通过 `[TREATMENT]` 模块设置。当前模型对全部13个Storage节点配置水质处理反应，每个Storage节点包含BODs、BODf、NH4、NO3、DO、TSSs、TSSn、TR_in和TR_ww共9种组分的处理公式。其中，BODs采用与水力停留时间相关的指数衰减形式，BODf采用线性削减形式，用于表达调蓄单元内有机物去除；NH4采用线性削减形式，削减的氨氮同步影响NO3变化；DO表达式同时包含复氧项和耗氧项；TSSs采用与停留时间相关的指数衰减形式；TSSn、TR_in和TR_ww保持不变，用作保守或示踪组分。主要水质反应配置如表3-2所示。

**表3-2  SWMM模型主要水质反应配置**

| 模块             | 组分                          | 当前设置                                        | 作用说明               |
| -------------- | --------------------------- | ------------------------------------------- | ------------------ |
| `[POLLUTANTS]` | BODf                        | Kdecay = 0.30 1/d                           | 管网输移过程中的快速可降解有机物衰减 |
| `[POLLUTANTS]` | BODs                        | Kdecay = 0.05 1/d                           | 缓慢可降解有机物或水解过程      |
| `[POLLUTANTS]` | TSSs                        | Kdecay = 0.10 1/d                           | 可沉降悬浮物衰减           |
| `[POLLUTANTS]` | NH4、NO3、DO、TSSn、TR_in、TR_ww | Kdecay = 0；CoPollutant = *                  | 不在管道衰减项中设置显式转化     |
| `[TREATMENT]`  | BODs                        | `C = BODs*exp(-0.15*HRT)`                   | Storage节点内有机物衰减    |
| `[TREATMENT]`  | BODf                        | `C = BODf - 2.0*BODf*HRT`                   | Storage节点内快速有机物消耗  |
| `[TREATMENT]`  | NH4                         | `C = NH4 - 20.0*NH4*HRT`                    | Storage节点内氨氮削减     |
| `[TREATMENT]`  | NO3                         | `C = NO3 + 20.0*NH4*HRT - 5.0*NO3*HRT`      | Storage节点内硝酸盐生成与削减 |
| `[TREATMENT]`  | DO                          | `C = DO + 30.0*(9.1-DO)*HRT - 2.0*BODf*HRT` | Storage节点内复氧与耗氧    |
| `[TREATMENT]`  | TSSs                        | `C = TSSs*exp(-0.3*HRT)`                    | Storage节点内悬浮物沉降    |
| `[TREATMENT]`  | TSSn、TR_in、TR_ww            | `C = 原变量`                                   | 保持不变或作为示踪变量        |

上述配置使水质转化主要发生在具有蓄水体积和水力停留时间的Storage单元中，而普通Junction节点主要承担水流汇合和完全混合，不设置显式处理反应。该处理方式既保留了主要水质组分的背景输移过程，又使后续节点级水质响应具有明确的仿真来源。

### 3.2.4 模型结构统计与输出变量

模型构建完成后，对节点、管段、边界和坐标信息进行一致性检查，以保证后续所有仿真场景均在相同拓扑结构下运行。研究子区SWMM模型共包含128个管网节点，其中包括113个Junction检查井节点、2个Outfall出流边界节点和13个Storage蓄水或调蓄单元；模型包含137条Conduit管段，并为每条管段设置独立断面属性。全部128个节点均具有平面坐标，可用于管网拓扑图绘制、空间分析和后续监测布局表达。模型结构统计如表3-3所示。

**表3-3  研究子区SWMM模型结构统计**

| 项目       |  数量 | 说明           |
| -------- | --: | ------------ |
| 全网节点     | 128 | 图结构表达与仿真输出范围 |
| Junction | 113 | 普通连接节点       |
| Outfall  |   2 | 出流边界节点       |

模型输出包括水力响应和水质响应两类。水力响应记录各节点在每个报告步上的水力状态变量，包括节点水深 `depth`、水头 `head`、蓄水体积 `volume`、侧向入流 `lateral_inflow`、总入流 `total_inflow`、总出流 `total_outflow` 和溢流量 `flooding` 共7个变量。其中，`depth` 反映节点处水面高程相对于节点底高的水深，是排水管网状态监测中较直接的观测指标；`total_inflow` 和 `total_outflow` 分别记录进入和离开节点的总流量，可用于反映节点局部水量扰动及上下游输移状态。水质响应记录各节点处9种水质组分的浓度变化，输出频率与水力变量一致。

这些节点级水力水质输出构成第3章后续数据生成的基础。3.3节将在该模型上叠加I/E缺陷扰动；3.4节通过PySWMM对缺陷场景进行批量仿真；3.5节则基于原始输出构造raw、residual和relative residual等模型输入特征。因此，3.2所建立的128节点全网模型不仅是SWMM仿真对象，也是后续时空图建模和缺陷定位任务的空间基础。

### 3.2.5 模型合理性检查

为保证SWMM模型能够支撑后续缺陷场景生成，本文从结构连通性、仿真稳定性、边界条件合理性和典型水力水质响应四个方面进行检查。结构连通性检查用于确认节点、管段和出流边界之间不存在影响仿真的孤立或错误连接；仿真稳定性检查用于确认模型能够完成连续时段计算，不出现发散、振荡或异常中断；边界条件检查用于确认上下游边界、出流口和调蓄单元设置与工程资料相一致；典型水力水质响应检查则结合现场监测获得的水位、流量及NH4、TSSs等指标，对正常工况下模型输出的量级和变化趋势进行判断。

在正常工况试算中，模型采用DYNWAVE动力波方法进行流量演算，流量单位为LPS，路由时间步长为60 s，并启用自适应时间步长。试算报告中的主要稳定性指标如表3-4所示。水力连续性误差为 -0.043%，绝对值远小于1%；9种水质组分的连续性误差绝对值均小于0.04%，说明水量与水质在仿真过程中保持良好质量守恒。水量平衡方面，48 h观测窗口内外部进流量为83.883×10⁶ L，外部出流量为82.707×10⁶ L，最终蓄水量为1.371×10⁶ L，进、出、蓄三项能够闭合。

局部连续性误差最大值出现在节点VP0232532，为4.17%；其余超过1%的节点包括HS1314512、HS1314505和YS2003067，误差分别为2.62%、1.58%和1.20%。这些误差主要表现为个别节点的局部行为，未扩展为系统性质量守恒问题。数值稳定性方面，所有137条管段均稳定运行，不收敛百分比为0.00%，每步平均迭代次数为1.01，说明模型在48 h观测窗口内能够稳定完成连续计算。
