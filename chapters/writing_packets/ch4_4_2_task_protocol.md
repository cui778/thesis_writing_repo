## 4.2 固定监测布局下的缺陷诊断任务与评价协议

### 4.2.1 诊断任务承接与正式实验协议

第3章已经完成I/E缺陷多场景仿真和节点级特征构造，形成统一节点顺序下的正式诊断数据集。第4章在该数据基础上开展固定监测布局下的缺陷诊断建模。与第3章关注数据生成过程不同，本章将数据集作为模型输入对象，重点研究在有限监测节点条件下，诊断模型如何从稀疏水力水质响应中识别缺陷活跃状态，并恢复缺陷发生位置。

本章采用第3章定义的全网节点集、候选缺陷节点集和固定监测节点集。全网节点数为128，候选缺陷节点数为50，固定监测节点数为25。固定监测布局采用Degree-N25方案，即以节点度数为依据选取25个监测节点作为观测位置。该布局在本章中保持不变，所有诊断模型均在相同监测节点集合下训练和评价。由此，本章模型比较的变量集中于诊断模型结构，而非监测节点集合差异。

本章正式实验数据集为 `ie420_plus_normal20_v1`，包含reference场景、IE420缺陷场景和normal扰动场景。其中，IE420缺陷场景提供受控I/E异常样本，normal扰动场景用于刻画无缺陷状态下的正常波动并约束误报。模型输入特征采用第3章构造的 `raw_plus_residual` 特征集，即4个原始变量、4个绝对残差变量和4个相对残差变量，共12维节点特征。对于任一场景 (s)，其全网节点时序特征可表示为：

[
\mathbf{X}_{s}\in \mathbb{R}^{T\times N\times F}
]

其中，(T=287) 表示有效时间点数量，(N=128) 表示全网节点数量，(F=12) 表示节点特征维度。固定监测布局通过观测掩码表示，记为：

[
\mathbf{m}\in {0,1}^{N}
]

当节点 (v) 属于Degree-N25监测节点集合时，(m_v=1)；否则 (m_v=0)。模型训练和评价时，动态观测仅来自掩码为1的监测节点；全网拓扑和候选缺陷节点集合则用于空间传播建模和定位排序。

本章正式实验采用场景级划分方式，即同一仿真场景派生的所有窗口样本划入同一数据子集。该划分方式保证训练、验证和测试之间在场景层面相互独立，避免同一缺陷过程的相邻窗口同时出现在训练集和测试集中。模型诊断种子采用7、42和123，主结果报告不同随机种子下的统计表现。

**表4-1  第4章固定监测布局诊断实验协议**

| 项目      | 正式设置                     | 说明                                            |
| ------- | ------------------------ | --------------------------------------------- |
| 数据集     | `ie420_plus_normal20_v1` | reference + IE420缺陷场景 + normal扰动场景            |
| 特征集     | `raw_plus_residual`      | 4 raw + 4 residual + 4 relative residual，共12维 |
| 全网节点数   | 128                      | SWMM研究子区完整节点空间                                |
| 候选缺陷节点数 | 50                       | I/E缺陷定位排序空间                                   |
| 固定监测节点数 | 25                       | Degree-N25监测布局                                |
| 监测布局    | `degree_N25`             | 第4章固定观测条件                                     |
| 数据划分    | `scenario split`         | 按场景划分训练、验证和测试                                 |
| 输入窗口长度  | 36个时间步                   | 10 min采样下约6 h                                 |
| 窗口滑动步长  | 6个时间步                    | 10 min采样下约1 h                                 |

表4-1给出了第4章诊断实验的统一协议。该协议将数据集、特征集、监测布局、候选空间、窗口设置和随机种子全部固定，使后续模型比较能够在相同输入条件和评价口径下展开。第4章后续各节所报告的主模型结果、任务层级结果和方法机制分析，均以该协议作为基本实验边界。

### 4.2.2 窗口样本、标签与双任务输出

排水管网I/E缺陷具有持续时间属性，其响应过程会在多个连续时间点上表现为水力水质状态变化。为了刻画缺陷发生过程中的时序响应，本章将每个场景的节点时序特征切分为固定长度的窗口样本。设窗口长度为 (L=36)，窗口滑动步长为 (q=6)，则场景 (s) 中以时间索引 (a_k) 为起点的第 (k) 个窗口可表示为：

[
\mathbf{X}*{s,k}=\mathbf{X}*{s}[a_k:a_k+L-1,:,:]\in \mathbb{R}^{L\times N\times F}
]

其中，(L=36)、(N=128)、(F=12)。在10 min采样间隔下，单个窗口覆盖约6 h响应过程，窗口之间以约1 h步长滑动。该设置能够在保留缺陷持续响应片段的同时，形成足够密集的窗口级诊断样本。

固定监测布局下，模型实际可见的动态输入由观测掩码控制。对于窗口样本 (\mathbf{X}_{s,k})，其稀疏观测输入可表示为：

[
\widetilde{\mathbf{X}}*{s,k}=\mathbf{m}\odot \mathbf{X}*{s,k}
]

其中，(\odot) 表示按节点维度进行掩码操作。监测节点保留原始动态特征，非监测节点的动态观测被掩码处理。通过该方式，本章在模型输入层面模拟真实排水管网中“有限节点可观测、全网拓扑可利用”的诊断条件。

窗口样本对应两类监督标签。第一类为缺陷活跃标签，用于描述当前窗口是否与缺陷活跃区间发生重叠。设场景 (s) 的缺陷活跃区间为 ([t_s,t_s+d_s))，窗口时间范围为 ([a_k,a_k+L))，则窗口活跃标签可表示为：

[
y^{act}_{s,k}=
\begin{cases}
1, & [a_k,a_k+L)\cap[t_s,t_s+d_s)\neq \varnothing \
0, & [a_k,a_k+L)\cap[t_s,t_s+d_s)=\varnothing
\end{cases}
]

对于normal扰动场景，其所有窗口均为无缺陷窗口，活跃标签均为0。该标签用于训练模型识别缺陷是否在当前时间窗口中处于活跃状态。

第二类为定位标签，用于描述缺陷场景对应的真实候选缺陷节点。设候选缺陷节点集合为 (\mathcal{C})，且 (|\mathcal{C}|=50)。对于缺陷场景 (s)，其真实缺陷节点 (c_s\in\mathcal{C})，模型需要在50个候选节点上输出定位分数，并使真实缺陷节点获得较高排序。对于无缺陷normal场景，其窗口主要参与活跃识别和误报评价，不参与候选缺陷节点定位排序。

因此，本章诊断模型的窗口级输出包含两部分。第一部分为缺陷活跃概率：

[
\hat{y}^{act}*{s,k}=p*{s,k}\in[0,1]
]

该输出用于判断窗口 (k) 是否处于缺陷活跃状态。第二部分为候选节点定位分数：

[
\mathbf{z}_{s,k}\in\mathbb{R}^{|\mathcal{C}|}
]

其中，(\mathbf{z}*{s,k}) 的每一个元素对应一个候选缺陷节点的诊断分数。对 (\mathbf{z}*{s,k}) 按分数降序排列后，可得到窗口级候选节点排序结果。真实缺陷节点在排序列表中的位置用于评价模型的空间定位能力。

窗口级输出还可以进一步聚合为场景级诊断结果。活跃概率序列用于恢复缺陷活跃时间区间，候选节点分数序列用于形成场景级候选节点排序。通过该设置，本章能够同时从窗口级、事件级和场景级三个层面分析模型诊断表现。

### 4.2.3 固定布局诊断实验评价协议

第2章已经给出了分类识别、候选目标排序、时间区间恢复和多次实验统计的通用评价指标定义。本节进一步明确这些指标在第4章固定Degree-N25布局诊断实验中的具体统计对象和使用口径。

在缺陷活跃识别方面，本章以窗口为基本评价单元，将模型输出的活跃概率与窗口活跃标签进行比较。Active F1用于评价模型对缺陷活跃窗口的识别能力。由于normal扰动场景不包含真实缺陷，其窗口输出可用于评价模型在无缺陷条件下的误报水平。本章采用Normal Window FPR统计normal扰动窗口被判断为缺陷活跃的比例，以刻画模型对正常波动的区分能力。

在空间定位方面，本章以50个候选缺陷节点作为统一排序空间。对于缺陷窗口或缺陷场景，模型输出候选节点分数，并按分数从高到低形成候选列表。MRR用于评价真实缺陷节点在排序列表中的整体靠前程度，Top-1、Top-3和Top-5用于评价真实缺陷节点是否进入前1、前3和前5个候选位置。窗口级定位指标反映模型在局部时间片段中的空间判断能力，场景级定位指标反映模型对一个完整缺陷过程的综合定位能力。

在场景级报警与时间恢复方面，本章根据窗口级活跃概率序列恢复场景中的缺陷活跃区间。Scene F1用于评价场景层面的缺陷报警结果，Onset Error用于评价预测缺陷开始时刻与真实开始时刻之间的偏差，Active Interval IoU用于评价预测活跃区间与真实活跃区间的重合程度。这些指标从时间维度补充空间定位指标，使模型评价同时覆盖“是否发生缺陷”“缺陷发生在哪里”和“缺陷在何时活跃”三个方面。

本章主模型比较采用多随机种子统计口径。对于每类模型，分别在种子7、42和123下进行训练与评价，并报告主要指标的均值和样本标准差。均值用于反映模型在正式协议下的整体表现，样本标准差用于反映不同训练随机性下结果的稳定性。后续方法机制分析中涉及窗口长度、路径先验和单场景过程的实验，将在相应小节中说明其具体统计对象，并与本节定义的固定布局诊断评价协议保持一致。

综上，本节完成了第4章诊断任务、窗口样本、监督标签、模型输出和评价口径的定义。后续4.3节将在该任务协议下构建诊断模型体系，4.4节和4.5节则分别从模型性能和方法机制两个层面对诊断结果展开分析。
