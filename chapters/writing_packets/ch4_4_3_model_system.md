## 4.3 缺陷诊断模型构建与对比方法设置

### 4.3.1 诊断模型总体框架

在固定Degree-N25监测布局下，缺陷诊断模型的输入由四部分组成：节点级窗口特征、观测掩码、管网拓扑结构和水力路径先验。节点级窗口特征来自第3章构造的 `raw_plus_residual` 特征矩阵，观测掩码用于限定动态观测仅来自固定监测节点，管网拓扑用于描述节点之间的连接关系，水力路径先验用于表达监测节点与候选缺陷节点之间的传播条件。模型输出包括窗口级缺陷活跃概率和候选缺陷节点定位分数，分别服务于缺陷活跃识别和空间定位排序。

设第 (s) 个场景的第 (k) 个窗口输入为 (\mathbf{X}_{s,k}\in \mathbb{R}^{L\times N\times F})，其中 (L=36)、(N=128)、(F=12)。观测掩码记为 (\mathbf{m}\in{0,1}^{N})，管网邻接矩阵记为 (\mathbf{A}\in\mathbb{R}^{N\times N})，水力路径先验张量记为 (\mathbf{P})。则本章诊断模型可抽象表示为：

[
(\hat{y}^{act}*{s,k}, \mathbf{z}*{s,k})
=======================================

f_{\theta}(\mathbf{X}_{s,k}, \mathbf{m}, \mathbf{A}, \mathbf{P})
]

其中，(\hat{y}^{act}*{s,k}\in[0,1]) 表示窗口级缺陷活跃概率，(\mathbf{z}*{s,k}\in\mathbb{R}^{|\mathcal{C}|}) 表示候选缺陷节点定位分数，(|\mathcal{C}|=50)。不同模型之间的差异主要体现在 (f_{\theta}) 对时序响应、拓扑邻接和路径先验的利用方式上。

### 4.3.2 稀疏观测输入与统一特征表示

固定监测布局下，模型不能直接使用全网节点的动态状态。为模拟有限监测条件，本章对全网节点特征施加观测掩码，仅保留Degree-N25监测节点处的水力水质响应。对于任一窗口样本 (\mathbf{X}_{s,k})，稀疏观测输入定义为：

[
\widetilde{\mathbf{X}}_{s,k}[:,v,:]
===================================

m_v \cdot \mathbf{X}_{s,k}[:,v,:]
]

其中，(v) 表示节点编号。当 (m_v=1) 时，节点 (v) 为监测节点，其窗口特征被保留；当 (m_v=0) 时，节点 (v) 为非监测节点，其动态特征被掩码。模型仍保留非监测节点在图结构中的位置，使其可以在后续空间聚合过程中接收来自监测节点的结构化信息。

为了使不同模型具有可比性，本章所有诊断模型共享相同的数据集、窗口设置、特征维度、监测布局和候选定位空间。也就是说，不同模型接收相同的 (\widetilde{\mathbf{X}}*{s,k})、(\mathbf{m})、(\mathbf{A}) 和候选节点集合 (\mathcal{C})，并输出相同形式的 (\hat{y}^{act}*{s,k}) 和 (\mathbf{z}_{s,k})。由此，后续性能差异主要反映模型结构对稀疏观测响应、拓扑传播关系和路径先验信息的利用能力。

在节点表示层面，模型首先将窗口内的多变量时序特征编码为节点隐表示。记第 (v) 个节点在窗口 (k) 中的稀疏观测序列为 (\widetilde{\mathbf{X}}_{s,k,v}\in\mathbb{R}^{L\times F})，其初始节点表示可写为：

[
\mathbf{h}^{(0)}_{v}
====================

\phi_{\text{time}}(\widetilde{\mathbf{X}}_{s,k,v},m_v)
]

其中，(\phi_{\text{time}}(\cdot)) 表示时序编码函数，(m_v) 用于区分节点是否具有动态观测。对于监测节点，(\mathbf{h}^{(0)}*{v}) 主要由窗口内水力水质响应编码得到；对于非监测节点，(\mathbf{h}^{(0)}*{v}) 不包含可见动态观测，但保留节点在图结构和候选空间中的位置。该表示方式使诊断模型能够在统一节点空间上进行后续图传播和候选节点排序。

### 4.3.3 时序基线与常规图基线模型

为评价不同结构信息对诊断任务的作用，本章首先设置时序基线和常规图基线模型。此类模型不直接使用水力路径先验，而是分别从时间响应和拓扑邻接两个角度建立诊断参照。

GRU模型作为时序基线，用于刻画固定监测节点上的多变量时序响应。该模型将监测节点窗口序列输入门控循环单元，得到各监测节点的时序表示，并通过节点池化形成窗口级表示。窗口级表示随后输入双任务输出层，分别产生缺陷活跃概率和候选节点定位分数。GRU基线主要反映仅依赖监测节点动态响应时的诊断能力。

GCN模型作为常规图卷积基线，用于刻画固定邻接矩阵下的空间信息传播。设第 (l) 层节点表示为 (\mathbf{H}^{(l)})，则图卷积传播可表示为：

[
\mathbf{H}^{(l+1)}
==================

\sigma(\widetilde{\mathbf{D}}^{-\frac{1}{2}}\widetilde{\mathbf{A}}\widetilde{\mathbf{D}}^{-\frac{1}{2}}
\mathbf{H}^{(l)}\mathbf{W}^{(l)})
]

其中，(\widetilde{\mathbf{A}}=\mathbf{A}+\mathbf{I}) 表示加入自连接后的邻接矩阵，(\widetilde{\mathbf{D}}) 为对应度矩阵，(\mathbf{W}^{(l)}) 为可学习参数，(\sigma(\cdot)) 为非线性激活函数。GCN模型能够在管网邻接关系上聚合邻近节点信息，为后续路径先验模型提供拓扑参照。

LSTM-GraphSAGE模型用于结合时序编码和邻域聚合。该模型首先利用LSTM编码节点窗口序列，得到节点时序表示；随后通过GraphSAGE在图邻域内聚合节点信息。其第 (l) 层聚合形式可写为：

[
\mathbf{h}^{(l+1)}_{v}
======================

\sigma\left(
\mathbf{W}^{(l)}
\cdot
\left[
\mathbf{h}^{(l)}*{v}
\parallel
\operatorname{AGG}\left({\mathbf{h}^{(l)}*{u}:u\in\mathcal{N}(v)}\right)
\right]
\right)
]

其中，(\mathcal{N}(v)) 表示节点 (v) 的邻域节点集合，(\operatorname{AGG}(\cdot)) 表示邻域聚合函数，(\parallel) 表示向量拼接。该模型同时包含时序编码和局部拓扑聚合，适合作为常规时空图诊断基线。

上述三类模型分别对应时间响应、图邻接传播和时序—图联合表达。它们构成第4章模型比较中的基础参照组，用于说明在固定监测布局下，仅使用监测时序或常规邻接聚合时的诊断表现。

### 4.3.4 水力路径先验与单层路径注意力模型

排水管网中的缺陷响应并不只由拓扑邻接阶数决定，还受到管段长度、流向关系和高程差等水力路径条件影响。两个节点即使具有相同的图距离，也可能由于流向、路径长度和高程关系不同而表现出不同的响应传播特征。因此，本章在常规图结构之外构造水力路径先验，用于描述监测节点与候选缺陷节点之间的传播关系。

对于任意节点对 ((i,j))，水力路径先验向量定义为：

[
\mathbf{p}_{ij}
===============

[
d^{topo}*{ij},
d^{len}*{ij},
r^{flow}*{ij},
\Delta z*{ij}
]
]

其中，(d^{topo}*{ij}) 表示拓扑最短路径距离，(d^{len}*{ij}) 表示沿管网路径累计的管段长度距离，(r^{flow}*{ij}) 表示节点间流向关系，(\Delta z*{ij}) 表示节点间高程差。上述变量从不同角度描述节点间水力传播条件：拓扑距离反映连接步数，管段长度反映传播路径尺度，流向关系反映上下游传播方向，高程差反映水力坡降相关信息。

Hydraulic-Inverse模型将水力路径先验作为注意力偏置，引导候选节点从监测节点和相关结构节点中聚合诊断证据。设节点 (i) 为目标节点，节点 (j) 为可参与聚合的信息源节点，第 (l) 层注意力打分为：

[
e_{ij}^{(l)}
============

\frac{
(\mathbf{W}*{q}\mathbf{h}^{(l)}*{i})^{\top}
(\mathbf{W}*{k}\mathbf{h}^{(l)}*{j})
}{
\sqrt{d}
}
+
g(\mathbf{p}_{ij})
]

其中，(\mathbf{W}*{q})、(\mathbf{W}*{k}) 为可学习映射矩阵，(d) 为隐表示维度，(g(\mathbf{p}_{ij})) 表示由水力路径先验映射得到的注意力偏置。经过归一化后得到注意力权重：

[
\alpha_{ij}^{(l)}
=================

\frac{\exp(e_{ij}^{(l)})}
{\sum_{j'\in\mathcal{R}*{i}}\exp(e*{ij'}^{(l)})}
]

其中，(\mathcal{R}_{i}) 表示节点 (i) 的候选信息源集合。节点 (i) 的聚合表示为：

[
\mathbf{m}_{i}^{(l)}
====================

\sum_{j\in\mathcal{R}*{i}}
\alpha*{ij}^{(l)}
\mathbf{W}*{v}\mathbf{h}^{(l)}*{j}
]

Hydraulic-Inverse通过上述机制将节点内容相关性和水力路径条件共同纳入诊断表示。与仅使用邻接矩阵的图卷积相比，该模型能够区分不同路径条件下的监测响应来源；与仅使用时序模型相比，该模型能够将监测节点响应映射到候选缺陷节点空间中。因此，Hydraulic-Inverse在本章中作为单层路径注意力模型，用于评价水力路径先验对缺陷定位排序的作用。

### 4.3.5 多层水力路径注意力诊断模型

在单层路径注意力的基础上，本章进一步构建多层水力路径注意力诊断模型DeepAttn-L3。该模型以稀疏观测节点表示为初始输入，通过多层路径引导聚合逐步融合监测响应、拓扑结构和水力路径先验，最终形成面向候选缺陷节点的诊断表示。

设第 (l) 层节点隐表示为 (\mathbf{H}^{(l)}=[\mathbf{h}^{(l)}*{1},\mathbf{h}^{(l)}*{2},\ldots,\mathbf{h}^{(l)}_{N}])。在每一层中，模型首先基于节点内容相关性和路径先验计算注意力权重，再对相关节点表示进行加权聚合。第 (l) 层路径注意力聚合可表示为：

[
\operatorname{PathAttn}(\mathbf{h}^{(l)}_{i})
=============================================

\sum_{j\in\mathcal{R}*{i}}
\alpha*{ij}^{(l)}
\mathbf{W}*{v}^{(l)}\mathbf{h}^{(l)}*{j}
]

随后，节点状态通过残差连接和前馈变换进行更新：

[
\mathbf{h}^{(l+1)}_{i}
======================

\operatorname{FFN}^{(l)}
\left(
\mathbf{h}^{(l)}*{i}
+
\operatorname{PathAttn}(\mathbf{h}^{(l)}*{i})
\right)
]

其中，(\operatorname{FFN}^{(l)}(\cdot)) 表示第 (l) 层前馈网络。多层结构使模型能够逐层整合不同传播层级上的诊断证据：前层侧重将监测节点动态响应编码为结构化节点信息，中间层侧重融合路径相关的空间传播关系，后层侧重形成候选缺陷节点的定位表示。本文采用三层路径注意力结构作为DeepAttn-L3模型。

DeepAttn-L3的输出包含活跃识别和节点定位两个分支。对于窗口级活跃识别，模型对最终层节点表示进行全局聚合，得到窗口级表示：

[
\mathbf{g}_{s,k}
================

\operatorname{Pool}(\mathbf{H}^{(K)})
]

其中，(K=3) 表示路径注意力层数。窗口级活跃概率由分类头输出：

[
\hat{y}^{act}_{s,k}
===================

\sigma(\mathbf{w}*{act}^{\top}\mathbf{g}*{s,k}+b_{act})
]

对于候选节点定位，模型仅取候选缺陷节点集合 (\mathcal{C}) 中的节点表示，并为每个候选节点输出定位分数：

[
z_{s,k,c}
=========

\mathbf{w}*{loc}^{\top}\mathbf{h}^{(K)}*{c}
+
b_{loc},
\quad c\in\mathcal{C}
]

由此可得到候选节点分数向量 (\mathbf{z}_{s,k}\in\mathbb{R}^{50})。该设计使活跃识别分支利用窗口整体响应，定位分支则直接作用于候选缺陷节点表示。两个分支共享前端时序编码、图结构信息和路径注意力表示，从而在同一诊断框架内同时完成时间状态识别和空间节点排序。

### 4.3.6 训练目标与实验配置

本章诊断模型采用双任务联合训练目标，包括窗口级活跃识别损失和候选节点定位损失。活跃识别分支将窗口是否处于缺陷活跃状态作为二分类任务，采用二元交叉熵损失：

[
\mathcal{L}_{act}
=================

*

\left[
y^{act}\log(\hat{y}^{act})
+
(1-y^{act})\log(1-\hat{y}^{act})
\right]
]

定位分支将真实缺陷节点作为候选节点分类目标。对于缺陷活跃窗口，设真实缺陷节点在候选集合中的索引为 (c^{*})，候选节点分数为 (\mathbf{z})，则定位损失为：

[
\mathcal{L}_{loc}
=================

*

\log
\frac{\exp(z_{c^{*}})}
{\sum_{c\in\mathcal{C}}\exp(z_c)}
]

normal扰动场景和无缺陷窗口主要参与活跃识别损失与误报约束；定位损失在具有明确缺陷节点标签的样本上计算。最终联合损失定义为：

[
\mathcal{L}
===========

\mathcal{L}*{act}
+
\lambda*{loc}\mathcal{L}_{loc}
]

其中，(\lambda_{loc}=0.5)，用于平衡活跃识别任务和空间定位任务。该训练目标使模型既学习缺陷是否活跃的时间判别能力，也学习真实缺陷节点在候选空间中的排序能力。

为保证模型比较的可比性，本章所有模型均采用第4.2节定义的正式实验协议。各模型使用相同数据集 `ie420_plus_normal20_v1`、相同特征集 `raw_plus_residual`、相同固定监测布局 `degree_N25`、相同场景级数据划分方式和相同随机种子设置。除模型结构差异外，训练与评价流程保持一致。正式模型比较报告随机种子7、42和123下的均值与样本标准差。
