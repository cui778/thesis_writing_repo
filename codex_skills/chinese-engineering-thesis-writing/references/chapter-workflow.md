# 两层论文写作流程

## 1. 固定结构

只保留两个管理层级：

```text
章节总纲
  -> 当前二级节写作卡
  -> 直接写入正文
```

三级标题和自然段属于正文结构，不建立额外写作包、状态机或任务文件。

## 2. 章节总纲

每章只建立一份章节总纲，固定：

- 本章研究问题与主结论；
- 全章故事线；
- 每个二级节的论证职责；
- 正式证据分配；
- 节与节之间的承接关系；
- 只允许出现一次的定义和结果；
- 本章向下一章交付的内容。

使用表格：

| 二级节 | 科学问题 | 承接内容 | 本节产出 | 正式证据 | 向后续交付 |
|---|---|---|---|---|---|

遵循：

- 一个二级节只承担一个主要科学问题；
- 方法定义早于结果引用；
- 主实验早于消融和边界；
- 个例不能早于总体结果；
- 章末小结不引入新数据。

## 3. 当前二级节写作卡

任务卡必须回答：

1. 本节要解决什么科学问题？
2. 本节在章节总纲中承担什么职责？
3. 读者进入本节前已经知道什么？
4. 本节结束后读者应接受什么结论？
5. 哪些证据是正式主证据？
6. 哪些材料只能作为补充？
7. 哪些结论明确禁止？
8. 下一节可以直接使用什么结论？

写作卡内部允许列出段落安排：

| 顺序 | 段落任务 | 证据 | 局部结论 |
|---|---|---|---|
| P1 | 问题或动机 | 前节结论/任务条件 | 为什么需要本节 |
| P2 | 方法或实验设计 | 配置/公式 | 如何回答问题 |
| P3 | 主要结果 | 表/图/数值 | 观察到什么 |
| P4 | 机制与佐证 | 消融/结构证据 | 为什么成立 |
| P5 | 边界与衔接 | 补充实验 | 向下一节交付什么 |

这是写作卡内部的段落计划，不构成第三个管理层级。

## 4. 文件组织

```text
chapters/writing_packets/
  ch4_master.md
  ch4_4_3_card.md
```

正文直接写入正式章节文件或临时 section draft。当前小节完成后，小节卡可归档；章节总纲持续保留并在必要时更新。

## 5. 全章闭合检查

检查三个映射：

### 研究问题映射

```text
章首问题 -> 方法设计 -> 对应实验 -> 结果 -> 章末结论
```

### 图表映射

每张正文图只承担一个主要论证角色。相同结果的替代图不同时进入正文。

### 术语映射

方法名、数据协议、节点集合、评价层次和指标名保持固定。若需要简称，首次出现时定义。
