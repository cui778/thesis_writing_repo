# 实验结果与分析写作

## 1. 实验小节的五层结构

中文工科硕士论文允许结果与分析合写，但必须区分五层：

1. **实验目的**：验证哪个方法假设；
2. **实验设置**：改变什么，固定什么；
3. **直接结果**：图表和关键数值显示什么；
4. **机制分析**：哪些结构或消融证据解释该结果；
5. **结论边界**：证据不能支持什么。

## 2. 结果段落

结果段落优先写有区分度的指标，不机械罗列全表：

```text
主指标绝对值
-> 相对关键参照的差值
-> 稳定性或误差
-> 次级指标是否一致
```

示例结构：

> 在统一协议下，模型A的MRR达到X，较最强参照B提高Y。Top-1与Event Top-1呈同方向变化，而Top-5接近饱和，因而性能差异主要体现在前位排序而非候选覆盖。

不得写“效果很好”“明显领先”而不提供对象与数值。

## 3. 机制分析

原因解释必须满足至少一种证据：

- 对应消融；
- 结构指标；
- 参数敏感性；
- 多 seed 一致性；
- 过程可视化；
- 与方法设计直接对应的控制实验。

若仅有相关现象，使用“与……一致”“表明……可能相关”，不写成确定因果。

## 4. 差异较小时如何写

强方法差异较小时，仍可形成有效结论：

- 先确认整体优化是否相对基础参照有效；
- 再比较不同方法是否以不同结构达到相近性能；
- 用稳定性、Top-K、误报、预算边界和结构独立性区分方法；
- 不放大0.005或0.01量级差异；
- 不因差异小而否定方法价值，也不强行制造冠军叙事。

## 5. 消融实验

消融必须对应明确假设：

| 消融 | 可回答问题 |
|---|---|
| 去除模块 | 模块是否有贡献 |
| 替换信息源 | 增益来自规则还是表征 |
| 改变层数 | 深度收益及饱和点 |
| 控制编码器 | 排除替代解释 |

单 seed 消融只能作为机制证据，不能替代多 seed 主结果。

## 6. 参数与预算实验

参数实验应识别：

- 单调趋势；
- 平台区；
- 交叉点；
- 性能与代价权衡；
- 适用范围。

若结果不单调，不强行拟合线性故事。检查是否存在相同节点集合、样本量不足或控制变量变化。

## 7. 段落语言

使用正式陈述：

- “结果显示……”
- “相对……提高……”
- “该变化主要出现在……”
- “结合……消融，可将该增益归因于……”
- “由于该实验仅包含单一随机种子，该结果用于……而不用于……”

避免：

- “这一页主要想说明……”
- “我们可以看出效果非常好……”
- “为了让故事更完整……”
- “本图服务于我们的结论……”
