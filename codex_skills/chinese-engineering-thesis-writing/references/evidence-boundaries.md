# 证据等级与结论边界

## 1. 证据等级

| 等级 | 证据 | 可支持结论 |
|---|---|---|
| E1 | 正式多 seed 主实验 | 核心性能与稳定性结论 |
| E2 | 正式多 seed 消融 | 模块贡献与替代解释排除 |
| E3 | 单 seed 控制实验 | 机制线索与趋势 |
| E4 | 结构统计/相关分析 | 关联机制，不支持确定因果 |
| E5 | 典型场景/个例图 | 过程解释和可视化示例 |
| E6 | 历史或旧协议结果 | 追溯，不进入正式结论 |

低等级证据不得独立支撑高强度结论。

## 2. 结论措辞

| 证据情况 | 推荐措辞 |
|---|---|
| 多 seed 一致且差异明确 | “结果表明”“支持” |
| 单 seed 或间接证据 | “结果显示”“与……一致” |
| 相关统计 | “相关”“伴随”“不能由……单独解释” |
| 个例 | “该案例展示”“用于说明过程” |
| 证据不足 | “尚不能判断”“有待进一步验证” |

“显著”仅在统计检验或明确约定的显著性依据存在时使用。

## 3. 禁止推断

- 由单一最好均值推断方法全面最优；
- 由低 Jaccard 推断高性能；
- 由最近距离推断水力可观测性充分；
- 由单 seed 趋势推断稳定规律；
- 由样本不均衡分组推断类型适应性；
- 由相关图推断因果机制；
- 由 Top-5 饱和推断精确定位能力；
- 由个例动画推断全部场景规律。

## 4. 证据冲突处理

发生冲突时：

1. 核对数据协议和文件来源；
2. 核对 seed、预算、数据划分和指标定义；
3. 优先采用正式原始结果；
4. 将旧结论标记为历史口径；
5. 若仍无法解释，不强行统一，明确记录冲突。

## 5. 事实标签

起草阶段可临时使用：

- `[E1]` 正式多 seed；
- `[E3]` 单 seed；
- `[FIG]` 图件证据；
- `[CODE]` 代码定义；
- `[NEEDS_CITATION]` 需要外部文献；
- `[NEEDS_DATA]` 当前证据不足。

合并正式正文前移除标签，但保留写作包中的追溯记录。
