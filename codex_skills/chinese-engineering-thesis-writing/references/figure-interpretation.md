# 论文图件解读规范

## 1. 图件进入正文前的五问

1. 图回答什么科学问题？
2. 图属于主结果、消融、机制、敏感性、个例还是边界？
3. 图的数据来自哪个正式协议？
4. 图中最有区分度的视觉编码是什么？
5. 图能够支持和不能支持哪些结论？

## 2. 正文分析结构

图件分析通常由两至四个自然段组成：

### 图形定义

简要说明坐标、颜色、点形、误差线或子图含义。只解释阅读所需信息，不复述完整图注。

### 主要结果

指出关键数值、组间差异、趋势、平台区或异常点。优先分析视觉上真正有区分度的部分。

### 机制联系

将结果与方法设计、消融或结构统计联系起来。不得凭图形外观直接推导因果。

### 结论边界

说明单 seed、个例、饱和指标、样本不均衡或非严格控制实验造成的限制。

## 3. 多面板图

每个面板必须有独立任务，同时组成一个论证链：

```text
Panel A：主现象
Panel B：机制或结构解释
Panel C：边界或稳定性
```

若面板之间没有逻辑依赖，应拆图。不得为了“信息量”强行组图。

## 4. 常见图型的分析重点

| 图型 | 重点 |
|---|---|
| Forest/点误差图 | 均值、误差、参照差值、排序稳定性 |
| Heatmap | 高低模式、行列结构、饱和区，避免只念颜色 |
| Pareto scatter | 支配关系、折中点、代价与收益 |
| Dumbbell | 同一对象两条件差值及方向 |
| 拓扑空间图 | 位置、覆盖盲区、传播区域，不以视觉接近代替最短路 |
| 时间剖面 | 响应起点、峰值、持续性、预测与真实区间 |
| 个例图 | 解释过程，不替代总体统计 |

## 5. 图注与正文分工

图注回答“图是什么”；正文回答“图说明了什么”。图注应包含数据范围、误差定义和必要缩写。正文不重复所有图注信息。

## 6. 图件审查

正文引用图件时核对：

- PNG/SVG 与 cleaned CSV 是否一致；
- 图件编号和路径是否属于正式索引；
- 是否误用了旧协议图；
- 图内指标与正文数值是否一致；
- 是否将饱和指标当成核心差异；
- 是否把个例写成全体规律。
